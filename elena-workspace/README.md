# elena-workspace

Пакет модів для Claude Code: запобіжники наукових робіт і YouTube, панелі «Хід роботи» і «Канали», рядок стану, сповіщення, теми і банер режиму.

## Підключення

```
claude --plugin-dir "шлях\до\elena-workspace"
```

Або назавжди: у `~/.claude/settings.json` додати в `env` змінну `CLAUDE_CODE_PLUGIN_DIRS` зі шляхом до теки.

## Модулі

Кожен модуль вмикається і вимикається окремо в `/config` (розділ плагіна elena-workspace) або в `settings.json`, `pluginConfigs["elena-workspace"].options`.

| Ключ | Модуль |
|---|---|
| `nauka_vydacha` | хук «Перед видачею файлу» |
| `nauka_zaglushky_blok` | блокувати видачу через «[уточнити]» (вимкнено: лише попередження) |
| `nauka_kb` | хук «Захист бази знань» |
| `nauka_dzherela` | хук «Фільтр джерел» |
| `nauka_panel` | панель «Хід роботи», рядок стану, сповіщення |
| `nauka_komandy` | команди наукового конвеєра |
| `youtube_komandy` | команди YouTube |
| `youtube_panel` | панель «Канали», рядок стану YouTube |
| `youtube_zakhyst` | захист метрик і транскриптів |
| `vyhliad_temy` | теми, акцент режиму, типографіка |
| `vyhliad_baner` | банер режиму |
| `vault_path` | шлях до сховища Obsidian |
| `kanaly` | власні канали через кому |
| `chasovyi_poias` | часовий пояс для перемикання тем (Europe/Kyiv) |

## Команди

Наука: `/нова-робота`, `/доопрацювання`, `/стан`, `/перевір-інструменти`, `/джерела-kb`, `/вичитати`, `/супровідні`.
YouTube: `/хук`, `/сценарій`, `/опис`, `/транскрипт`, `/ідея`.
Службові: `/режим [наука|youtube]`, `/журнал-моду`.

Команди лежать у `commands/` і працюють навіть без мода. З модом вони отримують його дані: перевірку файлу, вміст стратегії каналу, перелік каналів.

## Збої

Збій мода не зупиняє роботу: дію пропущено, запис у журнал. Журнал показує `/журнал-моду`.
